# Repaso Matemáticas Primaria

Aplicación en Python con Tkinter para ayudar a niñas y niños de primaria a practicar matemáticas de forma divertida e interactiva.

## Características

- Ejercicios de suma, resta, multiplicación y división.
- Estructura extensible para agregar más tipos de ejercicios (fracciones, decimales, lógica, series, etc.).
- Interfaz gráfica amigable para niños.
- Pensado para el aprendizaje autónomo y el refuerzo escolar.

## Instalación

1. Clona este repositorio:
   ```sh
   git clone https://github.com/chakalito/repaso_matematicas.git
   cd repaso_matematicas
   ```

2. Crea un entorno virtual:
   ```sh
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Instala los requisitos:
   ```sh
   pip install -r requirements.txt
   ```

## Uso

Ejecuta el programa principal:
```sh
python main.py
```

## Objetivos educativos

- Reforzar el cálculo mental y la comprensión de operaciones básicas.
- Fomentar el aprendizaje autónomo y el juego educativo.
- Cubrir el temario de matemáticas de primaria.
